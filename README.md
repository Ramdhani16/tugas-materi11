# 📊 Program Peringkat Nilai Siswa - Bubble Sort (Descending)

Projek ini berisi implementasi algoritma pengurutan (**Bubble Sort**) untuk mengurutkan data nilai ujian siswa secara menurun (*descending*). Program dibuat menggunakan bahasa Python dengan studi kasus pengurutan peringkat dari nilai tertinggi hingga terendah.

---

## 🚀 Fitur Program
* **Struktur Data Terstruktur:** Menggunakan format *list di dalam list* untuk menjaga kesatuan data nama dan nilai siswa sesuai dengan contoh materi kuliah.
* **Sorting Descending:** Logika perbandingan diubah menjadi `if arr[j][1] < arr[j+1][1]` sehingga nilai terbesar otomatis menempati posisi teratas.
* **Penomoran Peringkat Otomatis:** Menampilkan hasil akhir lengkap dengan label "Peringkat 1" hingga "Peringkat 8" secara berurutan.
